Building an Execution Layer Around Existing Desktop Software

Large volumes of product and receiving data had to be typed by hand into legacy desktop software that could not be replaced. We built a controlled automation layer around it. In production, 21,531 product records have been entered without manual typing — roughly 714 hours of manual entry avoided.

The problem

Large volumes of product and receiving data were entered by hand into legacy desktop software.

The solution

A controlled execution layer around the existing software:

  • Structured Excel input and field preparation
  • Desktop automation
  • OCR and matching support
  • Status write-back and logs
  • Exception handling
  • Human verification

Results

Measured

  • In production, used by about 2 people
  • 7 completed product-entry batches
  • 21,531 product records processed
  • Receiving workflow also in production

Operating estimate

  • About 714 hours of active manual entry avoided — roughly 4–5 person-months

The record count comes from completed production batches confirmed by the project owner. Hours refer to active human operating time, not machine runtime.

Key principle You do not always need to replace software before you can automate the work around it.
