Services

Website & Catalog Operations

We keep large product websites accurate. Supplier price lists, datasheets and stock files go through one controlled pipeline: parse, match, diagnose, human approval, bulk write with rollback, and read-back verification. On a ~64,000-product catalog, price updates verified 386 of 386 after writing.

What we do

  • Parse supplier price lists, datasheets and inventory files, however messy
  • Decide what should be on sale and match it to existing listings
  • Diagnose a price change before applying it — a small adjustment, or a full repricing?
  • Test, normalize, upload and verify product images
  • Write changes in bulk — every change ships with a rollback and a per-item change record
  • Re-read the live catalog to confirm that what was written matches what was calculated
  • Turn missing data into a ready-to-send request for the supplier
  • Clean up the storefront: brand pages, duplicates, listing status
  • Build new websites and web tools end to end: domain, DNS, hosting, pages, uploads and live apps

How it works

  1. Supplier price list, datasheet and inventory file
  2. Read-only snapshot of the live catalog
  3. Parse and clean the supplier files
  4. Decide what should be on sale
  5. Match to existing listings
  6. Price-change diagnostic
  7. Human approval
  8. Bulk write with rollback
  9. Read back and reconcile
  10. Exception list and supplier data request

Proven in

  • Keeping a 64,000-product online catalog accurate Measured
  • zeror.ca — our own site, from domain registration to live tools

Questions

Which e-commerce platforms do you work with?
Our production work so far is on OpenCart. The method — snapshot, match, preview, write with rollback, read back — does not depend on the platform.
What happens to products with missing prices or images?
They are not published. They go into a supplier request sheet that lists exactly what is missing for each product.
Can catalog updates run automatically on a schedule?
Today every production write is released by a person. Scheduled updates with automatic checks and rollback are designed but not yet built.
