下面列出案例中各项工作的进展：已在日常使用、已用真实数据测试、正在进行，或只完成了设计。

已上线

流程做什么
网站商品目录流程供应商文件 → 匹配 → 改价诊断 → 人工批准 → 带回滚的批量写入 → 回读（案例）
图片流程用真实请求测试供应商图片链接，规格化、上传、逐张核验
老旧软件录入结构化输入 → 桌面自动化 → 状态回写（案例）
价格与库存查询一次查询覆盖供应商和内部数据（案例）

已在真实数据上测试

流程做什么
发票 PDF → 结构化数据供应商发票 → 固定格式的明细行，附对账合计（案例）
SKU 与商品身份匹配处理前缀、空格和变体差异；不确定的匹配上报人工，绝不强配。一次测试中，45 个型号对约 6,500 条记录，匹配上 44 个
商品规格补全尺寸、单位换算、技术规格、双语文字和来源标注——从官方来源补全，绝不猜
商品 / 价格 / 库存准备多来源的商品表，缺口明确标出

进行中
